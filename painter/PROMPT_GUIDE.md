# 提示词指南：参考功能注意事项

本指南只说明开启参考功能时提示词要注意什么。
结论来自 2026-10-10 在 anima-base 上的对照实验。
PCK = 输出与目标骨架的吻合度，≥0.6 算跟随。

## 1. 只开人物参考

| 问题 | 结论 | 依据 |
|---|---|---|
| 要不要写人物特征？ | **可以不写，但推荐写 2~5 个核心特征** | 不写特征也能还原发型/发色/服装；写上后瞳色、长袜等细节更稳定 |
| 能不能写和参考图不一样的特征？ | **不能（除非有意修改）** | 提示词会覆盖参考：写 `black hair, red eyes` 后发色瞳色直接变了，服装仍保留 |
| 想换衣服怎么办？ | 正向写新服装，**负向写旧服装的标志部件** | 只写 `white sundress` 时 1/2 张残留了原水手领和红领巾 |

模板：
```
正向: {质量词}, 1girl, solo, {核心特征: 发色, 发型, 瞳色}, {服装: 沿用写原服装 / 换装写新服装}, {动作}, {构图}, {场景}
负向: {通用负向}, {换装时: 原服装部件，如 sailor collar, neckerchief, school uniform}
```

- `1girl/1boy, solo` 必须与参考人物一致。
- 构图、场景、表情、动作照常写，参考不会限制它们。

## 2. 只开动作参考

| 问题 | 结论 | 依据 |
|---|---|---|
| 还要写动作词吗？ | **要** | 高踢腿：不写 PCK 0.82 → 写 0.90；举双手：不写 0.57（手臂常不举）→ 写 **1.00** |
| 只写动作词不开动作参考行吗？ | 不行 | 仅动作词 0.50，0/4 跟随 |
| 要写朝向吗？ | **必须写** | 骨架不含朝向信息，不写时多数画成背影；加 `facing viewer, looking at viewer, from front` 后 4/4 正面且 PCK 1.00 |
| 动作词能和骨架不一样吗？ | **不能** | 骨架高踢腿 + 提示词 `sitting` → PCK 0.59 且人体扭曲崩坏 |
| 构图词？ | 与骨架范围一致 | 骨架是全身写 `full body`；只有上半身写 `upper body` / `cowboy shot` |

模板：
```
正向: {质量词}, 1girl, solo, {外观}, {服装}, {与骨架一致的动作描述}, {朝向: facing viewer / from behind / from side}, {与骨架一致的构图}, {场景}
```

动作词示例：`high kick, leg up, standing on one leg` / `arms up, both arms raised, legs apart` /
`sitting, crossed legs` / `running` / `jumping` / `hand on hip` / `waving`。

## 3. 同时开人物参考 + 动作参考

1. 合并上面两条：**写动作词 + 朝向**，人物特征写 2~5 个核心特征，不写冲突特征，换装时负向写旧服装部件。
2. 人物参考图尽量用**中性站姿**的全身图。人物参考图本身的姿势会和动作参考竞争：中等动作（举手、叉腰）可以共存（4/4 跟随），
   极端动作（高踢腿）会被拉回参考图的站姿（0/4）。
3. 极端动作 + 人物的替代方案：先只开动作参考出图，后续用精细重绘阶段修正人物（接口已预留）。
