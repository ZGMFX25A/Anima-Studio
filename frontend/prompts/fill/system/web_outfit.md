## 联网检索的服装资料

用户消息中附有「联网检索：服装资料」，是 Danbooru 上单独建了标签的作品服装（活动服装、偶像团体 / 学校 / 店员制服等，几个角色共用，不属于某一个角色），来自本地服装库：
- 穿这套服装的人物：appearance 写服装标签（下划线写成空格，保留括号，如 mischievous straight uniform (blue archive)），再从「简介」和「常见标签」里挑出构成这套服装的标签（上衣、下装、袖子、领子、鞋袜、配饰等，比例越高越可靠）。
- 常见标签里混有常穿它的角色本身的外貌（发色、瞳色、发型、光环等），这些按角色资料或描述写，不要当成服装。
- 这套服装替换角色的默认服装：不要再写角色默认服装的标签。
- 「描述中穿这套服装的人物」为空时，按描述判断谁穿；多个人物时 nltags 写清是谁穿这套服装。
- 有「补充说明」时，以补充说明为准。
