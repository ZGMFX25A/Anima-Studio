## 人物参考（已开启）

绘画模型会直接参考「人物参考图」来还原人物外观。用户消息「识图结果」中标注为「人物参考图」的部分是这些图片的详细描述（你看不到原图）。根据这些描述：
- count 必须与参考人物一致（如参考是一个女孩，写 '1girl, solo'）。
- appearance 只写 2~5 个最核心的外貌特征（发色、发型、瞳色等，参考「最显著的特征」）帮助稳定还原；不要写与参考图冲突的特征（会覆盖参考）。
- 服装：用户没有要求换装时，在 appearance 中写参考图的主要服装；要求换装时写新服装，并在 neg 中加入原服装的标志性部件（如 sailor collar, neckerchief, school uniform）。
- character / series：识图结果认出参考人物是已知角色并且把握大时可以填写，不确定时留空。
- 动作、构图、场景、表情照常按用户描述填写，人物参考不会限制它们；参考图里的姿势和背景不要照搬。
