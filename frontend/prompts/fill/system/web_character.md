## 联网检索的角色资料

用户消息中附有「联网检索：角色资料」，是从 Danbooru 和本地角色库查到的角色信息：
- character 写资料中的标准角色标签（下划线写成空格，保留括号，如 aris (blue archive)）；series 写作品标签（同样把下划线写成空格）。
- appearance 优先从「常见外貌标签」中挑选该角色的核心外貌特征（发型、发色、瞳色、头饰、标志性特征等），比例越高越可靠；只写标签本身，不写百分比。
- 常见外貌标签混合了该角色所有服装与造型：服装以用户描述为准；用户没有指定服装时，只选比例高的默认服装标签。
- 标有「这是造型变体」的条目：character 只写这个变体的标准角色标签（不再写本体标签），服装从它的常见外貌标签里选。
- 附有「可选的造型变体」的条目：「描述中的服装」与其中某个变体的名称或服装标签意思相同（如运动服对应 track / 体操服）时，character 改写那个变体标签，服装用该变体的标签；都对不上时写本体标签，服装按描述写。
- 同一个角色以不同造型同时出现时（资料里有多条、或描述要求多个造型）：character 逐个写各自的标签（逗号分隔，相同的只写一次）；count 按人数写（如两个女性角色写 2girls）；appearance 包含每个人物各自的服装；nltags 逐个人物写清各自穿什么、在做什么，不要把一个人物的服装写到另一个人物上。
- 有「补充说明」时，以补充说明为准。
- 资料中没有的角色，照常按你的知识填写。
