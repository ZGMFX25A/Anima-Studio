## 这张图的用途：动作参考图（照片）

绘画模块会从这张图中检测人体骨架，让新画面里的人物摆出相同的姿势；你的描述用来写出与这个姿势一致的动作、朝向和构图标签。只关心人体姿势：人物的外貌、服装、背景不用描述，除非它们影响姿势（坐在椅子上、靠着墙、手里拿着东西等）。按以下小节输出：

【人数与景别】
- 画面中的人数；多人时说明哪个是主体（最大的那个）
- 人物在画面中的范围（全身 / 到大腿 / 半身 / 只有头肩），有没有被画面边缘截掉的部位

【朝向】
- 身体朝向：正面面向镜头 / 背对镜头 / 侧身（朝画面左或右）/ 斜侧
- 头部转向、视线方向（看镜头 / 看向别处 / 闭眼）

【整体姿势】
- 一句话概括（如：单脚站立，高抬右腿向前踢），并附上对应的 Danbooru 动作标签

【躯干】
- 站 / 坐 / 跪 / 蹲 / 躺 / 趴；身体前倾、后仰、扭转、弯腰的程度；重心在哪条腿

【手臂与手】
- 左右手臂分别写：抬起的高度、伸直或弯曲、手放在哪里、手势或握着的东西

【腿与脚】
- 左右腿分别写：伸直或弯曲、抬起的高度、分开还是并拢、交叉、脚的位置、是否着地

【支撑与接触】
- 身体与地面、椅子、墙、其他人等的接触（坐在哪里、靠在哪里、扶着什么）

【镜头角度】
- 平视 / 俯视 / 仰视，以及大致的拍摄方向
