## 这张图的用途：灵感参考图

用户想参考这张图画一张新图，可能参考其中任何方面（人物、服装、动作、构图、场景、氛围……）。请全面、细致地描述，按以下小节输出：

【整体】
- 画面类型（插画 / 照片 / 游戏截图 / 漫画分格等）与主题
- 人数与性别（对应 1girl / 2girls / 1boy / no humans 等）
- 内容尺度：日常 / 性感暗示 / 部分裸露 / 完全裸露或性内容

【人物】每个人物分别写以下各项（多人时逐个写，并标明称呼）：
- 身份：认出的角色名与作品（及把握大小），或「未能认出」；看起来的年龄段与性别
- 头发：发色（含挑染、渐变、内层色）、长度、发型、刘海、呆毛、侧发、发饰
- 脸部：瞳色、眼型、眉毛、妆容、痣、尖牙、脸红等
- 身体：肤色、体型、胸部大小，可见的身体特征（兽耳、尾巴、角、翅膀、光环、纹身、伤痕等）
- 服装：从上到下逐件写（外套、上衣、下装、袜子、鞋子、手套），每件写颜色、款式、材质、花纹和细节（领口、袖子、蝴蝶结、纽扣、蕾丝、褶边等），以及穿着状态（敞开、撩起、滑落、湿透、破损、没穿等）
- 配饰与持物：帽子、眼镜、项链、耳环、项圈、包、武器、道具等，写清戴在哪里、拿在哪只手

【动作与表情】
- 每个人物的姿势（站 / 坐 / 躺 / 跪 / 蹲 / 跑等）、身体朝向、头部方向、视线（看镜头 / 看向别处 / 闭眼）
- 双手、双腿分别在做什么、放在哪里
- 表情与情绪
- 人物之间的互动；性行为或性暗示的动作照实写出

【构图与镜头】
- 景别（全身 / 七分身 / 半身 / 特写）、镜头角度（平视 / 俯视 / 仰视 / 侧面 / 背面）
- 人物在画面中的位置、画幅方向（竖图 / 横图 / 方图）、景深与焦点

【场景与背景】
- 地点、室内或室外、时间（白天 / 傍晚 / 夜晚）、天气、季节
- 背景与前景中的物体和道具；纯色或简单背景写明颜色

【光线与色彩】
- 光源方向与类型（逆光、侧光、柔光、霓虹灯、阳光透过树叶等）、阴影
- 主色调与配色、整体氛围

【画风与媒介】
- 上色方式（赛璐璐、厚涂、水彩、像素等）、线条风格、是否 3D 或照片
- 画面中的文字、对话框、水印、签名
