## 这张图的用途：动作参考图（骨架图）

这是一张 DWPose / OpenPose 骨架图：黑色背景上，用彩色线条连接表示人体关键点的圆点。绘画模块会让新画面里的人物摆出相同的姿势；你的描述用来写出与这个姿势一致的动作、朝向和构图标签。

读图提示：
- 常见配色：脖子到人物右肩是红色、到左肩是橙红色；人物右臂是橙到黄色，左臂是黄绿到绿色；人物右腿（右胯到脚）是绿到青绿色，左腿是天蓝到深蓝色；脖子到鼻子是蓝色，脸部是紫色和品红色的短线。可以据此区分人物自身的左右；配色不同的骨架图以实际线条为准。
- 人物的右侧肢体出现在画面左侧，通常说明人物面向观众；出现在画面右侧，通常说明背对观众。脸部的点（鼻子、双眼、双耳）齐全一般是正面；只有一侧的眼睛和耳朵一般是侧面；没有鼻子和眼睛、只剩耳朵可能是背面。
- 有手部、脸部的细小关键点时，可以用来判断手势和头部方向。
- 骨架本身不能完全确定朝向：把握不大时明确写「朝向无法判断」，不要硬猜。

按以下小节输出：

【人数与景别】
- 骨架的数量；多个时说明哪个是主体（最大的那个）
- 骨架覆盖的范围（全身 / 到大腿 / 半身 / 只有头肩），有没有缺失的部位

【朝向】
- 身体朝向（正面 / 背面 / 侧身朝画面左或右 / 斜侧），写出判断依据和把握大小
- 头部转向

【整体姿势】
- 一句话概括（如：单脚站立，高抬右腿向前踢），并附上对应的 Danbooru 动作标签

【躯干】
- 站 / 坐 / 跪 / 蹲 / 躺 / 趴；身体前倾、后仰、扭转、弯腰的程度；重心在哪条腿

【手臂与手】
- 左右手臂分别写：抬起的高度、伸直或弯曲、手的位置；有手部关键点时描述手势

【腿与脚】
- 左右腿分别写：伸直或弯曲、抬起的高度、分开还是并拢、交叉、脚的位置

【镜头角度】
- 从骨架比例推测的大致视角（平视 / 俯视 / 仰视），把握不大时写「无法判断」
