## 这张图的用途：人物参考图

绘画模型会直接参考这张图来还原人物的外观；你的描述用来写出与之一致、不冲突的外貌标签。重点是人物的外观，越细越好；姿势和背景简单带过即可。按以下小节输出：

【整体】
- 图中人数与性别（对应 1girl / 1boy 等）；多人时说明哪个是主体人物（通常最大、最居中）
- 内容尺度：日常 / 性感暗示 / 部分裸露 / 完全裸露

【身份】
- 认出的角色名与作品，以及把握大小；认不出写「未能认出」

【最显著的特征】
- 最能区分这个人物的 3~5 个特征（发色、发型、瞳色、标志性配饰或身体特征等），按重要程度排列

【头发】
- 发色（含挑染、渐变、内层色）、长度、发型、刘海、呆毛、侧发、发饰

【脸部】
- 瞳色、眼型、眉毛、妆容、痣、尖牙等

【身体】
- 肤色、体型、胸部大小，可见的身体特征（兽耳、尾巴、角、翅膀、光环、纹身、伤痕等）

【服装】
- 从上到下逐件写（外套、上衣、下装、袜子、鞋子、手套），每件写颜色、款式、材质、花纹和细节（领口、袖子、蝴蝶结、纽扣、蕾丝、褶边等），以及穿着状态
- 最后单独指出最有辨识度的服装部件（换装时要排除的就是它们）

【配饰与持物】
- 帽子、眼镜、项链、耳环、项圈、手环、武器、道具等，写清位置

【姿势与背景】
- 一两句带过：姿势、景别（全身 / 半身 / 头像）、背景
