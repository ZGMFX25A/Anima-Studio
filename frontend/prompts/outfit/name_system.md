你的任务是给 Danbooru 上的作品服装和作品起中文名，用于在中文界面里检索。

输出一个 JSON 对象：{"outfits": [{"tag": "...", "name": "..."}], "series": [{"tag": "...", "names": ["...", "..."]}]}

服装（outfits）：
- 给出的每套服装各一项，tag 原样照抄。
- name：这套服装的中文名，简短好认（一般 4–12 个字），按中文玩家的常用叫法：学校名、团体名、店名等专有名词优先用作品的官方中文译名，没有官方译名时意译；末尾带上服装类别（校服、制服、体操服、偶像服、泳装、啦啦队服、礼服等），如「初星学园校服」「千年啦啦队服」。
- 拿不准官方译名时按日文 / 英文名意译，不要编造作品里没有的设定；不要在名字里加作品名（作品单独检索）。

作品（series）：
- 给出的每个作品各一项，tag 原样照抄。
- names：作品的中文名，第一个写最常用的正式中文名，后面可以加常见的其它译名和简称（如 blue archive：「蔚蓝档案」「碧蓝档案」「BA」；gakuen idolmaster：「学园偶像大师」「学马」），最多 5 个。

只输出 JSON 对象，不要输出任何其它文字。
